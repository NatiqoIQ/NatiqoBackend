# الحافة: WAF وDDoS وCDN (F23 / P2-8)

هذا المستند لا ينشئ بنية تحتية؛ يحدّد ما يجب أن يفعله مزوّد الحافة (Cloudflare أو AWS
CloudFront + WAF) قبل أن يُفتح النطاق للجمهور، والحدود التي يجب ألا تتعارض مع حدود
التطبيق الداخلية. يوجد في الكود `RateLimitMiddleware` لكل مستخدم/مسار (120 طلباً/دقيقة
عاماً، 30 للـAI، 120 للمصادقة والإدارة)، لكنه **لا يحمي من موجة قبل المصادقة**: الطلب
غير المصادق لا يصل إلى مفتاح المستخدم، وموجة 100 ألف IP تتجاوز أي حد لكل مستخدم.

## الترتيب

```
العميل → CDN/WAF (كاش الوسائط والكتالوج) → Ingress/Load Balancer → نسخ API
```

الأصول الثابتة (`/media/*`) تُقدَّم من CDN بـ`Cache-Control: public, max-age=31536000,
immutable` (F28)، ولا تمر إلى الـAPI إلا عند الـmiss. `GET /api/v1/content/*` قابل
للكاش على الحافة لدقائق (ETag موجود)، أما `/api/v1/quiz/*` و`/api/v1/ai/*` و`/api/v1/auth/*`
فلا تُكاش إطلاقاً.

## قواعد WAF الدنيا

| القاعدة | الإجراء | لماذا |
|---|---|---|
| Rate limit لكل IP على `/api/v1/auth/*` | 20 طلباً/دقيقة، حظر 10 دقائق عند التجاوز | Credential stuffing وdev-login probing؛ أعلى من 12 محاولة دخول شرعية للمستخدم الواحد |
| Rate limit لكل IP على `/api/v1/ai/*` | 60 طلباً/دقيقة | التطبيق يحدّ المستخدم عند 30؛ الحافة تمنع موجة حسابات مجهولة قبل الوصول |
| Rate limit عام لكل IP | 600 طلباً/دقيقة | أعلى من الاستخدام الشرعي لعائلة خلف NAT واحد، وأقل من مسح آلي |
| Body size | 1 MB عدا `/media` (10 MB) | رفع جسم ضخم قبل المصادقة يستهلك ذاكرة النسخة |
| Managed rules | OWASP Core Ruleset، حجب SQLi/XSS | لا تغني عن الاستعلامات المهيّأة، لكنها تزيل الضجيج |
| Bot Fight / Known Bots | تحدٍّ للبوتات عالية المعدل | حماية من scrapers على الكتالوج |
| Geo/ASN anomaly | تنبيه فقط في البداية | غالبية المستخدمين من العراق؛ لا تحجب قبل قياس |

## DDoS

- فعّل حماية DDoS المُدارة (Cloudflare L3/4/7 أو AWS Shield Standard) — لا تحتاج كوداً.
- اربط تنبيه `5xx > 1%` و`p95 > 400ms` و`natiqo_requests_in_flight` بتصعيد فوري؛
  الـWAF وحده لا يكفي إن كانت القاعدة أو Redis عنق الزجاجة.
- احتفظ بوضع «Under Attack» كزر تشغيل، لا كإعداد دائم: التحدي يضر بتطبيق جوال.
- حدّد سقف اتصالات Ingress لكل IP، ولا ترفعه أثناء الهجوم.

## أسرار الحافة

مفاتيح الـWAF/API tokens لا تُوضع في `.env` التطبيق ولا في Git؛ استخدم Secret Manager
نفسه (F23) أو متغيرات Terraform الحساسة. سجلات الـWAF تُصدَّر إلى نفس منصة السجلات مع
الاحتفاظ 30 يوماً على الأقل.

## ما لا يغطيه هذا المستند

- كتابة Terraform فعلي: يختلف بين Cloudflare وAWS ولا يمكن اختباره من هذه البيئة.
- WAF مخصّص لمنطق التطبيق (مثل منع إعادة إرسال إجابات)؛ هذا عمل التطبيق لا الحافة.
